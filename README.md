# Cifras Charles

Aplicativo web para organizar músicas, cifras e sequências de repertório.

## Como usar

Abra `index.html` no navegador ou rode um servidor local e acesse pelo celular na mesma rede.

Recursos atuais:

- Biblioteca de músicas com busca por nome ou estilo.
- Leitura em tela cheia.
- Texto grande para celular distante.
- Aumento e redução da fonte por botões.
- Ajuste de tamanho com gesto de pinça na área da cifra.
- Sequências de músicas por estilo ou ocasião.
- Cadastro e edição de músicas no próprio navegador.
- Dados salvos no `localStorage` do aparelho.

## Próximo passo recomendado

Importar automaticamente as músicas do arquivo `.docx` original e gerar a biblioteca inicial real.
